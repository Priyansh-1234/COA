Question 1: Binary–Gray Code Converter
Design and simulate a combinational circuit that converts a 4-bit binary number into its equivalent Gray code and converts the generated Gray code back into binary.
The complete design must contain the following Verilog modules.

5. Verilog Design Requirement
The design must follow the modular hierarchy specified above.
Students may use suitable combinational Verilog constructs such as:
• gate primitives;
• continuous assignment using assign; or
• combinational always @(*) blocks.
The design must be purely combinational. No clock, flip-flop, latch, or other sequential logic
is required.

6. Testbench and Simulation
Write a testbench for the top-level code_converter_top module.

0000 through 1111.

binary_recovered = binary_in.
The behavioral simulation waveform must show at least:

gray_out,
