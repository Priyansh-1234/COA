2. Why There Are Three Parity Groups
Each parity bit checks a particular group of Hamming positions.
The groups are determined from the binary representation of the position number.
• p1 checks every position whose least significant binary position bit is 1.
• p2 checks every position whose second binary position bit is 1.
• p4 checks every position whose third binary position bit is 1.
Therefore:

Notice, for example, that Hamming position 6 has binary position number
6 = (110)2 .
Therefore, position 6 belongs to the p2 and p4 parity groups, but not to the p1 parity group.
This property will later allow the syndrome to identify the location of an erroneous bit.

6. Error Injection Using an Error Mask
In an actual communication system, a transmitted bit may change because of noise or another
physical error.
During Verilog simulation, such an error must be deliberately created so that the errordetection circuit can be tested.
For this purpose, use a 7-bit signal
error_mask[6:0].
The error mask is not part of the Hamming coding algorithm. It is only used to imitate
corruption of the transmitted codeword during simulation.
The received word is defined as
received_codeword = encoded_codeword ⊕ error_mask

7. Complete Worked Error Example
Continue with the earlier data:
data = 1011.
The encoder generated
encoded_codeword = 1010101.
First consider the case with no error:
error_mask = 0000000.
Therefore,
received_codeword = 1010101 ⊕ 0000000
= 1010101.
All parity checks pass, so
syndrome = 000
and
error_detected = 0.
Now suppose the bit at Hamming position 6 is corrupted.
Position 6 corresponds to
codeword[5].
Therefore, use
error_mask = 0100000.
The received word becomes
6

received_codeword = 1010101 ⊕ 0100000
= 1110101.
Now check the three parity groups.
For the s1 check:
s1 = r1 ⊕ r3 ⊕ r5 ⊕ r7 = 1 ⊕ 1 ⊕ 1 ⊕ 1 = 0.
Thus the p1 group still passes.
For the s2 check:
s2 = r2 ⊕ r3 ⊕ r6 ⊕ r7 = 0 ⊕ 1 ⊕ 1 ⊕ 1 = 1.
Thus the p2 group fails.
For the s4 check:
s4 = r4 ⊕ r5 ⊕ r6 ⊕ r7 = 0 ⊕ 1 ⊕ 1 ⊕ 1 = 1.
Thus the p4 group also fails.
The syndrome is therefore
syndrome = {s4 , s2 , s1 } = 110.
Since
(110)2 = 6,
the syndrome correctly identifies that the corrupted bit is at
Hamming position 6 .
This can also be understood directly from the parity groups:
6 = (110)2 .
Position 6 belongs to the p2 and p4 groups, but not the p1 group.
Therefore,
s4 = 1,

s2 = 1,

s1 = 0,

giving
syndrome = 110.

9. Logic-Driven Design Requirement
The encoder and syndrome generator must be implemented as combinational logic networks.
Students may use:
• Verilog xor, or, and not gate primitives;
• continuous Boolean assignments using assign;
• wires for intermediate signals; and
• module instantiation.
The Hamming-code generation and syndrome generation must not be implemented using:
• case statements;
• large if–else mappings; or
• manually entered lookup tables.
The purpose of the assignment is to realize the Hamming parity equations directly using
combinational logic.
No clocked or sequential logic is required.
